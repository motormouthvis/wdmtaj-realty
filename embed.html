Dream Neighborhood Embed Guide

Instructions for adding the inline neighborhood map to listing or neighborhood pages on your website.

Dev/QA only: This test site includes an environment switcher (top-right corner). Click the pill to toggle between STAGING and PRODUCTION instantly. The switcher rewrites all Dream Neighborhood script and iframe URLs on the fly.
Most important rule: Put the embed in its own full-width section — not inside a content column or sidebar layout.

The embed snippet

Add this once per page, where the map should appear:

<div id="dn-explorer"></div>
<script src="https://app.dreamneighborhood.com/explorer/inline.js" async></script>

For staging/testing, use https://staging.dreamneighborhood.com/explorer/inline.js instead.

The script auto-detects the property or neighborhood address from the page, the same way the popup SDK does.

What to avoid

Do not place the snippet inside Bootstrap columns, sidebars, cards, fixed-width wrappers, or any parent with overflow: hidden.

<div class="container">
  <div class="row">
    <div class="col-lg-8">
      <h1>Neighborhood Name</h1>
      <div id="dn-explorer"></div>  <!-- constrained — do not do this -->
      <script src="https://app.dreamneighborhood.com/explorer/inline.js" async></script>
    </div>
    <div class="col-lg-4">Sidebar</div>
  </div>
</div>

Recommended layout (Bootstrap)

<div class="container pt-5">
  <h1>Georgetown</h1>
  <p class="lead">Neighborhood description...</p>
</div>

<div class="container-fluid px-0">
  <div id="dn-explorer"></div>
  <script src="https://app.dreamneighborhood.com/explorer/inline.js" async></script>
</div>

<div class="container pb-5">
  <p>More neighborhood details...</p>
</div>

Pages with a sidebar

Keep the sidebar with the page intro. Place the explorer in a separate full-width block below that row.

<div class="container pt-5">
  <div class="row">
    <div class="col-lg-8">
      <h1>Agent Name</h1>
      <p class="lead">Bio...</p>
    </div>
    <div class="col-lg-4">Contact card</div>
  </div>
</div>

<div class="container-fluid px-0">
  <div id="dn-explorer"></div>
  <script src="https://app.dreamneighborhood.com/explorer/inline.js" async></script>
</div>

<div class="container pb-5">
  <div class="row">
    <div class="col-lg-8">
      <!-- remaining content -->
    </div>
  </div>
</div>

Optional CSS

After the HTML structure is correct, this helps the iframe fill the section:

#dn-explorer,
#dn-explorer iframe {
  width: 100%;
  max-width: 100%;
  display: block;
}

CSS alone cannot fix a snippet placed inside a narrow column. Fix the HTML layout first.

Do not use CSS breakout hacks

Avoid width: 100vw; margin-left: -50vw; tricks. They fail inside Bootstrap rows, flexbox, grid, and overflow-hidden parents.

Pre-launch checklist

Snippet is not inside .col-* or a sidebar column☐
Snippet is in its own full-width block☐
Intro and body content use normal containers above/below☐
No overflow: hidden on parents wrapping the explorer☐
Only one #dn-explorer per page☐
Address is present on the page for auto-detection☐
